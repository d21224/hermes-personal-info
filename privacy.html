개인정보처리방침

이 도구는 계정 소유자가 승인한 Google API 권한으로 필요한 일정·파일 정보를 처리합니다. 공개 안내 사이트에는 Google 계정 로그인, 일정, 파일 내용, 인증키를 저장하지 않습니다.

자동화 실행 환경에는 인증 토큰과 작업에 필요한 데이터 및 로그가 보관될 수 있습니다. 브리핑 작성에는 설정된 AI 제공자가 사용될 수 있으며 결과는 소유자가 지정한 메시징 채널로 전달됩니다. 해당 서비스의 데이터 처리 정책도 적용됩니다.

Google 사용자 데이터를 판매하거나 광고 목적으로 사용하지 않습니다. Google API에서 받은 정보의 사용 및 전송은 Limited Use 요건을 포함한 Google API Services User Data Policy를 준수합니다.

소유자는 Google 계정의 서드파티 연결 설정에서 접근을 철회할 수 있습니다. 철회는 이미 생성된 로그·메시지를 자동 삭제하지 않으며 실행 환경과 전달 채널에서 별도로 삭제해야 합니다. 필요한 기간만 보관하며 불필요한 데이터는 삭제합니다.

이 안내 사이트는 자체 분석·광고 스크립트를 사용하지 않습니다. 호스팅 제공자인 GitHub는 서비스 운영을 위한 접속 정보를 처리할 수 있습니다.
